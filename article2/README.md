## Три методологические ловушки, разобранные в работе

1. **Оценка на малой тестовой выборке.** Разделение по годам дало macro-F1 = 0,98 на
   87 наблюдениях; перекрёстная проверка на 1647 наблюдениях — 0,664 ± 0,023.
2. **Признак, кодирующий исход.** «Категория программы» со значением «крио ПЭ» сама
   означает отсутствие пункции: AUROC 0,995.
3. **Признак, доступный только после исхода.** Спермограмма сдаётся в день пункции;
   при любом заполненном значении пункция состоялась в 96–100 % записей. AUROC 0,987
   до исключения, 0,743 после.

Для систематического поиска применён одномерный скрининг: AUROC одиночного признака
выше 0,85 расценивается как признак утечки. Выявлено 13 таких признаков, все —
эмбриологические показатели, регистрируемые после пункции.

## Экспертная разметка: почему не использована как целевая переменная

Врач-эксперт разметил 3056 циклов при включённой алгоритмической подсказке по АМГ.
Метка совпала с подсказкой **в 3056 случаях из 3056**; медиана времени решения
0,93 с, 62 % решений быстрее секунды. Метки представляют собой перекодировку АМГ, а не
независимое суждение, поэтому целевыми переменными служат фактические исходы циклов.

Наблюдение вынесено в статью как самостоятельный методологический результат.

## Воспроизводимость

Зерно генератора случайных чисел 20260802 (совпадает со статьёй №1). Расчёты
выполнены на вычислительном сервере в каталоге `~/ivf2`. Исходные выгрузки
использовались в режиме чтения, персональные данные в анализе не участвовали и в
результаты не попадают.

Порядок запуска:

```
python 33_all_models.py      # семь прогностических задач
python 34_deep_mining.py     # разведка признаков, скрининг утечек
python 35_clean_and_models.py# проверка кодирования пропусков
python 40_figures_mdpi.py    # рисунки
```

Среда (NixOS, менеджер пакетов pip недоступен):

```
OMP_NUM_THREADS=3 nix-shell -p "python313.withPackages(ps: with ps; \
  [numpy pandas scikit-learn scipy matplotlib openpyxl])" --run "python <скрипт>"
```

Ограничение `OMP_NUM_THREADS=3` обязательно: без него нагрузка доходила до 43 при
16 ядрах и замедляла расчёт.
